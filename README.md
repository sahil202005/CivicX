# 🚀 CivicX – AI Powered Smart Civic Issue Reporting & Management Platform



## 📌 Overview

**CivicX** is an AI-powered Smart City platform that connects **Citizens**, **Municipal Authorities**, and **Registered Workforce Agencies** through an intelligent civic issue management system.

The platform uses **Google Gemini AI** to automatically classify complaints, identify locations, assist citizens through an AI chatbot, and streamline issue resolution.

---

# ✨ Features

- 🤖 Google Gemini AI Integration
- 🗺 Interactive GIS Mapping
- 📍 GPS Based Issue Reporting
- 🏛 Authority Ward Management

- 🔐 OTP Authentication

# 🏗 System Workflow

```
Authority Creates Ward
        │
        ▼
Citizen Registers & Reports Issue
        │
        ▼
Gemini AI Classifies Complaint
        │
        ▼
Authority Reviews Report
        │
        ▼
Authority Assigns Workforce
        │
        ▼
Workforce Resolves Issue
        │
        ▼
Citizen Gets Resolution Update
```
